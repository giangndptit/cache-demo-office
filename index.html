Cache Demo (Static HTML + CSS)

Trang này hiển thị “CSS version” bằng pseudo-element. Nếu CSS bị cache, bạn sẽ thấy version cũ dù đã “deploy”.

Trạng thái

  • CSS Version đang hiển thị:
  • Gợi ý: Mở DevTools → Network → chọn file CSS → xem from disk cache / Cache-Control.
HTML CSS Javascript

Kịch bản demo

  1. Load trang lần đầu → thấy CSS Version (v1).
  2. Giữ nguyên link ./css/style.css, sửa nội dung file style.css thành v2 rồi deploy lại.
  3. Nếu server/CDN set cache dài cho CSS, nhiều máy vẫn thấy v1 (kẹt cache).
  4. Cách đúng: đổi URL CSS (vd: style.v2.css hoặc file có hash).
